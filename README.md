# The Way Back Home

A true Bible story for children ages 5–8, from Creation to the Cross, the empty tomb, and the new creation. Free to read online or download as a PDF in 13 languages: English, Chinese (Mandarin), Hindi, Spanish, French, Arabic, Bengali, Portuguese, Russian, Urdu, German, Hebrew, and Plautdietsch.

- `index.html` — home page with the language list
- `read.html?lang=xx` — full-screen, page-by-page reader with optional read-aloud
- `pdf/` — downloadable PDFs, one per language
- `pages/<lang>/` — page images used by the reader
- `audio/<lang>/` — recorded narration (optional)
